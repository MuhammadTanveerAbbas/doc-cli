# Changelog

All notable changes are listed here. The format follows Keep a Changelog and the project uses semantic versioning.

## 0.1.0

First release.

Added:

1. Interactive shell, banner, command palette, tab completion, and shell completion scripts.
2. System, packages, developer setup, runtimes and tools, performance, history, projects, Git, network, downloads, backup, security, AI, plugins, updater, and settings commands.
3. Permission service with plans, dry run, approval rules, elevation rules, and an audit log.
4. Redacted local history with search, export, replay, and retention.
5. Package manager adapters for npm, pnpm, Yarn (detection), Bun, pip, uv, APT, DNF, pacman, Homebrew, and winget.
6. Self update logic with channel selection, checksum verification, and rollback for standalone installs.
7. Test suite, CI workflows for Linux, Windows, and macOS, and install scripts.

Known gaps are listed in the README under "Honest status of this release".
